Junk packets

Sends random frames before the handshake so that DPI cannot match a fixed pattern. Works on TCP (UoT) only.

TCP fragmentation

Splits the first handshake into tiny TCP segments with a pause between them, so DPI does not see the whole signature at once. Works on TCP (UoT) only.
