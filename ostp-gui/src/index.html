Junk Packets

Sends random garbage frames before the Noise handshake to confuse DPI pattern matching. Active in UoT/TCP mode only.

TCP Fragmentation

Splits the initial handshake into tiny TCP segments with delays between them. Prevents DPI from reading the full handshake signature. Active in UoT/TCP mode only.
